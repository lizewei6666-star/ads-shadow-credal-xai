# Aggregate results

The files in `predictive/` and `pag/` are compact aggregate outputs from the
formal analysis. They are included so that manuscript tables and figures can be
reproduced without rerunning the expensive model-refitting and null-reference
workflows.

These tables are analysis outputs, not substitute inputs for the full workflow.
The predictive analysis must begin from `data/ads_crashes.xlsx`; the PAG
extension must read a completed predictive run with matching fingerprints.

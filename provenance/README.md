# Provenance

`formal_run_meta_sanitized.json` retains the dataset hash, software versions,
model set, split design, shadow contract, and source-code hash from the
completed formal analysis. Local machine paths were replaced before release.

The publication copy replaces personal absolute paths with repository-relative
defaults and shortens module documentation. No statistical setting or
computational function was changed. `SHA256SUMS.txt` identifies both the frozen
formal sources and the files distributed in this repository.
